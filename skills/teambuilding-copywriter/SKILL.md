## 2026-11-06｜全平台内容目标与团建SEO话题（高优先级）

**业务目标明确**：这套技能生成的全部小红书与抖音笔记，均面向江浙沪企业团建相关搜索和潜在客户，而不是普通旅游内容创作。内容呈现保留自然分享感、多人互动氛围、具体玩法及有用的参考节奏；**不能因“生活攻略”模式而自动删掉团建搜索意图**。但内容实际用于获客时，应如实遵守商业内容规则，不能以“朋友游玩分享”的外观虚构亲历或掩盖旅游经营性质。

### 五版通用话题词规则

- **第一优先：本批作品的真实目的地＋团建**，如桐庐写 `#桐庐团建`、溧阳写 `#溧阳团建`、安吉写 `#安吉团建`；不得把其他批次的地名混入。
- **重点客源城市词**：`#杭州团建`、`#上海团建`、`#苏州团建`，对于真实面向这些城市组织团队且具备相应经营/发布资格的作品，原则上三项均保留。此处“杭州／上海／苏州”表示目标客源地，**不表示活动实际位于三个城市**；标题与正文仍应如实标示实际目的地。若服务覆盖地或用户本轮约束不同，按真实性调整。
- **小红书三版**：总计8–10个真实相关话题。优先使用 `#目的地团建 #杭州团建 #上海团建 #苏州团建` 四个核心槽位；其余4–6个从实际项目、景点、季节、地区与活动氛围中选，不凑无关城市词或未经证实的项目。
- **抖音两版**：仍控制4–5个话题，但**不再强制只能使用纯生活泛流量词**。在账号具备相应商业发布资格、实际发布内容和资质要求相符时，默认5词为 `#目的地团建 #杭州团建 #上海团建 #苏州团建 #实际核心玩法或景点`。前四项服务于精准搜索，第五项服务于内容匹配；不要以 `#朋友出游` 等泛流量话题挤占核心词。**抖音正文仍保持生活化、无强招徕、无虚构个人经历**，但这不意味着团建话题不会被平台认定为营销。
- **现实处罚红线优先于SEO**：若账号不具备实际经营行为所需资质或尚未确认发布资格，不能只把推广文本改成日常口吻就当作合规；应明确提示发布风险/资质缺口，不把带团建推广话题的稿件标为已经确认可发布。话题本身不是被证明的单词黑名单，需按标题、正文、画面、账号与真实业务综合判断。

**发布态检查**：检查5版是否都有符合平台数量上限的“目的地团建＋目标客源城市团建”SEO结构；抖音单独审查旅游业无资质营销风险。其他规则与本条冲突时，以本条的**话题搜索意图**为准，以既有**真实性与资质门槛**为安全边界。

## 2026-11-03｜发布态术语防泄漏与反PPT硬质检（最高优先级，先于字数/密度）

**事实来源特殊处理**：用户贴来的旧版AI文案、竞品文案或反面样稿属于“待审文本”，**不等于用户已确认全部服务细节真实**。除非同批原始资料或用户明确确认，不能将旧稿里的车辆座数、酒店配置、保险、雪具包含、接待人数和具体服务承诺重新包装成确定事实。

**用户实测反例**：一篇滑雪年会稿被写成“江浙沪2天1夜年会方案全要素清单”，正文又有“一、全要素服务矩阵明细”“【项目标的】”“【方案定位】”“三、咨询方式”，还未经证实地写了具体大巴座数、酒店设施、雪具包含、教练、保额、精修摄影与“留人数+预算获取排期”。这表明旧版“内部称全要素、标题别写全要素”的提醒**不足以拦截**，必须逐版对最终标题＋正文做发布态硬检查。

### A. 内部风格标签与外部发布文本严格隔离

- “高密度全要素方案版 / full-element-plan / 服务矩阵 / 项目标的 / 方案定位 / 综合服务 / 全要素”属于**内部写作和业务分析元数据**，不是读者搜索词或种草卖点。它们可以作为代码块外的版本名和MULTI的分隔符，但**不得出现在任何一版直接发布的标题或正文**，除非用户明确要求写一篇解释这些概念的文章。
- **机械硬检查**：抽取五版每一篇独立的纯发布正文（去掉代码围栏、版本名、`VERSION_START/END` 等分隔标记），搜索`全要素`、`服务矩阵`、`项目标的`、`方案定位`、`综合服务`、`咨询方式`。命中即判本版 **FAIL_INTERNAL_TERM_LEAK**，必须**重写相关标题或整段**再验收。不能仅把词删掉而留下PPT腔。内部版本标签允许出现“全要素”，不因此误报。
- 发布稿小标题优先真实内容：`🗓️两天参考安排`、`⛷️滑雪怎么玩`、`🏡住宿怎么选`、`🎯适合哪些团队`、`🍲吃什么`、`🎮可选玩法`。不按投标文件章节写`一、交通保障`、`二、服务矩阵`、`三、咨询方式`。
- **标题约束再提升**：≤20字符之外，必须有实际景点/玩法/氛围/决定性选择价值之一；SEO最多围绕1—2个主词自然组织。不同地域叠加、长串功能词、内部分类词、毫无证据的“保姆全案/一站式”等标题均重写。比如已确定桐庐、滑雪、年会和温泉选项时，可考虑“桐庐年会团建⛷️滑雪＋温泉”，但`温泉`必须有本轮已核实的泡汤事实，不能因旧参考图/范例而添上。

### B. 商业承诺与示例项目防迁移

- 最终稿出现**具体包车座数、高速/过桥费、雪具租赁包含项/滑雪时长、教练服务、民宿全地暖/天然私汤/会议室配置、固定人数承接范围、保险额度、摄影精修、行程固定到达时刻**等细粒度运营事实时，逐项追问是否来自**本批真实用户材料或已确认业务能力**。若缺，删除或明确为未确定的可选方向，不用“全套、含、标配、全程提供”造承诺。
- `30万保险`、`33/53座大巴`、`15–80人` 等看起来像参数的数字没有真实依据时直接判 **FAIL_UNSUPPORTED_CLAIM**；不能用模糊“均已包含”替代。
- 没有已确认资质与平台准入时，绝不凭“无营销”改写方式声称旅游/团队服务推广一定符合平台规则。
- 不默认输出`留下人数+预算`、`领取详细方案`、`私信获取`、`咨询方式`、`加微`等强转化CTA。**这不是所有词在所有场景下的永久违法判定**；只是本项目的默认公开稿不承接这些营销动作。

### C. 输出前强制闭环（每一版都做，不可只在模板里提醒）

1. **看标题**：是否含`全要素`等内部标签、超过20字符、只堆关键词而没有一个真实玩法/画面钩子？
2. **看正文**：是否出现商务招标/PPT腔的段落名、营销承接CTA或不证实的服务矩阵/配置清单？
3. **看证据**：把数字、保额、含项、设施、包栋、温泉、雪场装备、交通和时刻等承诺逐项对本批来源；无依据就删。
4. **看交付**：修正后再检查字数、话题、U+2800、3/4版行程和独立/MULTI/TXT逐字一致性。**有任一FAIL则不得把该稿当可发布完成稿交付**；不够素材就交代事实缺口。
5. 不需要每次大段展示质检过程，但必须实际按此顺序执行。**仅把禁止项写进SKILL.md，不等于已经通过质量检查。**

### 默认快速生产｜来源锁定＋分层阅读（2026-10-30.1）

**唯一权威技能是本公开仓库 `zwmopen/skills-public/skills/teambuilding-copywriter/`。** 不读取旧私有技能。本 `SKILL.md` 高于一切历史样例；用户临时约束仅在不违反真实性和平台要求的范围内生效。

**写文案≠每次重做素材研究。默认走快速生产，只有关键事实不明时才进入补充分析。**

1. **先锁定当前作品批次**：只处理当前用户点名的这套作品。首批视觉母版、过往批次、旧文案、样例与AI生成效果图都不是当前作品的事实来源；用户当轮确认的信息优先。
2. **文字优先**：读取本套用户消息、TXT、MD中与内容相关的事实；已覆盖目的地、项目、时长、餐饮、住宿等要素时，不为重复确认而逐张提取图中文字。不得因此遗漏用户明确要求核对的关键信息。
3. **图片按任务读取**：当文字缺少关键事实，或图片承载了关键的地点/项目/参数，使用原生视觉能力直接查看当前素材图片；对大量图片按当前作品范围整理一次即可。只有图片文字模糊且确实影响核心事实、其他途径无法辨认时，才考虑OCR；**禁止无必要地为所有图片批量OCR**。读不清的关键内容不猜测。
4. **生成图和母版仅作视觉参考**：除非原始图、文字或用户明确确认支撑，否则不得把生成图中出现的服务、设施或体验写为事实。

6. **结尾＋话题**：一句自然收尾或收藏价值；按本文件2026-11-06的「全平台团建SEO」生成4–5个含目的地、目标客源地的相关话题（需实际经营与发布资格匹配），不写商业引流CTA。

### 排版与密度硬要求

- **短段密集、信息足量、好复制**：同一主题1–3句，项目用Emoji小标题分行，时间节奏按一行一个节点排列。只在**主要内容板块之间**使用**单独一行 U+2800「⠀」**；不允许每一句话前后都加空白行、连续多层留白，也不允许整篇长段流水账。
