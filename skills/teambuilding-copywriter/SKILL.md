# 团建文案 Skill｜公开版

## 版本身份与同步关系

这是**公开分享版（Public Mirror）**，不是内部生产主仓库。

- 公开仓库：`zwmopen/skills-public`
- 当前目录：`skills/teambuilding-copywriter/`
- 适用对象：在线 ChatGPT、Claude、手机端 GPT 等免登录联网直接调用，或复制到其他 Skill 工具中。
- 私有主版本：位于 `zwmopen/skills` 私有仓库，由作者内部维护，不对外开放。

### 同步原则

私有主版本是规则真源。凡是**适合公开分享**的文案能力升级，均实时同步到本仓库，包括：
- 默认三版本与顺序；
- 小红书自然攻略 / 小红书高密度种草 / 抖音无营销规则；
- 标题 ≤ 20 字符硬门、长度门禁、U+2800 排版；
- 高密度种草模板与时间轴授权；
- 事实门与去生产过程旁白；
- 抖音严格 ≤ 5 个话题标签与去涉旅敏感词。

## 目标

把用户提供的团建、周边游、农庄、营地、景区、活动方案、原始笔记或已制作的文案素材，改写成可直接发布的双平台文案。

默认输出固定为 3 个独立代码块：

1. **<<<VERSION_START:红书自然>>> 小红书1｜自然攻略版**
2. **<<<VERSION_START:红书高密度>>> 小红书2｜高密度种草版**
3. **<<<VERSION_START:抖音无营销>>> 抖音｜攻略版**

## 一、共同事实规则

先建立“事实账本”，只使用当前输入中明确支持的信息。

### 可以直接使用
- 目的地 / 城市 / 场地
- 明确季节
- 明确玩法
- 明确天数
- 明确人数
- 明确交通方式
- 明确住宿 / 餐饮 / 项目
- 长期业务能力（如大巴可按预算安排、10人起接等）

### 不得凭空编造
- 虚构价格 / 人均
- 固定车程
- 固定接待容量
- 景区营业时间
- 虚构客户案例 / 评价
- “刚带完某公司 / 0差评 / 老板夸爆”

---

## 二、小红书1｜自然攻略版

### 目标
像成熟运营本人写的真实攻略，顺口、自然、信息够用，动静节奏搭配合理。

### 推荐结构
- 标题 ≤ 20 字符（有画面感，不套“怎么玩”泛壳）
- 场景/痛点/选择结论开头
- 基础信息（📍地点、👥人数、🎯核心玩法）
- 玩法拆解（🔥想活力 / 🚴想轻松 / 🍵想松弛 / 🍢想互动）
- 傍晚怎么收尾
- 💡HR搭配参考
- 1组必要提醒（温差/防滑/开放确认）
- 8—10 个搜索标签

### 长度
素材充足时约 **650—850 发布字符**，不为了凑字编事实。

---

## 三、小红书2｜高密度种草版

### 核心感觉
- 标题搜索感强（优先：地点团建｜项目A+项目B+项目C）
- 第一屏有情绪（秋高气爽 / 逃离工位 / 山野漫游）
- 参数卡清晰（📍地点 / ⏰时长 / 🙋‍♀️人数 / 🚌大巴 / 🎯关键词）
- 亮点密度高（⭐行程亮点速览，4—6项，带具体爽点与判断）
- 参考时间轴（🗓️ 1日行程参考 / 2天1夜参考，四位数字时刻）
- 玩法池丰富（🍁【秋日限定体验池】，3列整齐矩阵）
- Emoji有视觉导航作用
- SEO话题完整（8—10个）

### 长度
素材充足时目标 **850—1000 发布字符**，1000字符以内即可交付。

---

## 四、抖音｜攻略版（无营销）

### 单目的地
优先改写成普通用户周末散心/自驾视角：
- 周末玩法 / 户外体验 / 避坑与节奏 / 治愈放空
- **彻底消杀涉旅营销词**：严禁出现团建、HR、行政、方案、策划案、大巴接送、报价、人均、预约、下单、私信
- **严禁出现方案腔表头**：不得使用“DAY 1 / 行程安排 / 活动流程”等表头
- **硬上限最多 5 个标签**：精选 4—5 个生活/自驾/户外标签，绝不输出第6个

### 长度
约 **450—650 发布字符**。

---

## 五、标题规则

先找 3—5 个真实钩子，再写标题。

优先：
- 具体项目组合（如：水杉森林+骑行皮划艇+围炉）
- 真实场景与画面
- 选择难题与明确收益

降低优先级：
- XX怎么玩 / XX怎么搭 / XX怎么选 / XX这样安排 / N个方向参考

禁止靠天花板、杀疯了、老板夸爆等硬造点击。单标题 ≤ 20 字符。

---

## 六、排版与防吞行留白

段落之间统一使用单独一行的 Unicode U+2800：

`⠀`

不要使用裸空行、HTML空格、`<br>`。保持手机端阅读呼吸感。

---

## 七、发布稿净化（看不见生产过程）

最终发布稿不要出现生产过程旁白：
- 严禁出现：`原文参考 / 原素材 / 图片显示 / 根据资料 / 这里没有提供 / 本文整理` 等生产过程话语。
- 有事实就直接写，没有依据直接省略，不对读者解释。
