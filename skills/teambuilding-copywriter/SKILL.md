# 团建文案 Skill｜公开版

## 2026-10-28.4｜默认四种小红书＋一篇抖音（当前规则）

已将两种高密度写法拆为独立默认模式。先前“三篇小红书＋一篇抖音”是历史合同，现在**默认5份独立成稿**：

1. **小红书1｜自然攻略版**：650—850发布字符，偏真实体验、取舍、自然攻略口吻。
2. **小红书2｜大纲方案版**：700—900发布字符，完整HR/行政收藏型参考方案，具体玩法与可操作节奏，非简化问答卡。
3. **小红书3｜高密度种草版**：900—980发布字符，≤1000。情绪第一屏＋参数卡＋吸睛项目亮点＋一条可选参考日程＋可选玩法池＋SEO，优先展现“值得去、怎么玩得丰富”。
4. **小红书4｜高密度全要素方案版**：900—980发布字符，≤1000。完整DAY参考排期、餐饮住宿（仅有依据时）、备选景点、团队组合。允许**一条主线路＋多项备选**或**两套互斥的完整方案并列比较**；绝不把两套行程叠在一天/两天里。
5. **抖音｜攻略版**：450—650发布字符、话题≤5；独立处理平台差异与经营资质风险，普通生活化语气不代表自动合规。

用户明确只要其中部分、或要求总共四篇/只小红书时，以当轮要求覆盖默认。若使用`<<<COPY_FORMAT:MULTI>>>`，需要依次输出四篇小红书和一篇抖音的五段完整文案，每段以`<<<VERSION_END>>>`闭合，段落留白用U+2800。

**私有参考库（不公开原文）核对数据**：自然攻略主锚点5篇、大纲方案主锚点5篇、高密度种草专属原文1篇、全要素方案完整原文2篇。另有跨版本共用的30篇完整风格原稿及8篇抖音黄金范例；相同内容引用只计一次。这是学习用的写作样本数量，**不等于发布表现/过审保证**。

**事实原则**：无当前输入证据，不编造实测、满意度、项目营业时间、车程、包栋设施、温泉、接送/包含关系、价格与安全承诺。可根据真实时长与项目规划清楚标注“参考”的时间节点，但不能伪造实际行车与项目开放。涉及旅游服务营销要核实相应主体资质及平台权限，不能靠换词替代。

## 一、共同事实规则

先建立“事实账本”，只使用当前输入中明确支持的信息。

### 可以直接使用
- 目的地 / 城市 / 场地
- 明确季节
- 明确玩法
- 明确天数
- 明确人数
- 明确交通方式
- 明确住宿 / 餐饮 / 项目
- 长期业务能力（如大巴可按预算安排、10人起接等）

### 不得凭空编造
- 虚构价格 / 人均
- 固定车程
- 固定接待容量
- 景区营业时间
- 虚构客户案例 / 评价
- “刚带完某公司 / 0差评 / 老板夸爆”

## 二、小红书1｜自然攻略版

### 目标
像成熟运营本人写的真实攻略，顺口、自然、信息够用，动静节奏搭配合理。

### 推荐结构
- 标题 ≤ 20 字符（有画面感，不套“怎么玩”泛壳）
- 场景/痛点/选择结论开头
- 基础信息（📍地点、👥人数、🎯核心玩法）
- 玩法拆解（🔥想活力 / 🚴想轻松 / 🍵想松弛 / 🍢想互动）
- 傍晚怎么收尾
- 💡HR搭配参考
- 1组必要提醒（温差/防滑/开放确认）
- 8—10 个搜索标签

### 长度
素材充足时约 **650—850 发布字符**，不为了凑字编事实。

## 三、小红书2｜大纲方案版

### 2026-10-28 双高密度独立写作模式（默认各写一篇）

“高密度种草”与“高密度全要素”不再混成同一种表现：

| 模式 | 着重回答的问题 | 常见组织 |
|---|---|---|
| `high-density-seeding` 高密度种草 | 这个地方哪里好玩、有哪些项目值得看？ | 情绪钩子＋亮点与参数卡＋重点项目＋简要参考行程＋丰富可选玩法池 |
| `full-element-plan` 高密度全要素方案 | 团队怎么组织活动、怎么排两天、吃住行与备选怎么搭？ | 景点/玩法总览＋完整DAY参考排程＋可选活动＋有依据的餐饮住宿/景点建议＋不同团队的组合 |

全要素模式还可以分为：**一条主行程加各类可选内容**；或**两条互斥、适合不同团队的完整参考行程**。后者须明确两条方案是替代而非叠加；每条方案内部的A/B也是互斥选项。多场地、不同住宿不能因为列在同篇就被写成一个套餐。

如果出现“实际带队体验、全员好评、零踩雷、确定温泉/房间设施、固定车程、某景区开放时间、两周/三周限定”等断言，只能在本次有可信依据时使用；内容参考不等于项目事实，不能从历史样例继承。

**当前默认已确认：四篇小红书＋一篇抖音，共五版。** 高密度种草与高密度全要素分别交付，而不是二选一。本公开仓库只同步通用写作结构，不收录私有参考全文。

### 核心感觉
为HR/行政提供可收藏的完整方案大纲，区别于自然攻略的生活口述，以及高密度种草的强画面和大量玩法池。

- 标题≤20字符，要有具体场景或可用价值。
- 基础信息：地点、时长、人数（有依据时）、核心体验方向。
- 玩法选择：各项目的强度、适合谁、怎么搭配。
- 行程参考：有真实输入时保留DAY、具体时刻；没有时刻时只用上午/下午/傍晚，不把策划时间冒充真实数据。
- 组合建议和集中一条天气/开放/安全提醒；8—10个精准话题。
- 素材充足时目标700—900发布字符，不是300字四问四答简表。
- 四个小红书版本独立构思，不得只换标题和小节名。

## 四、小红书3｜高密度种草版

### 核心感觉
- 标题搜索感强（优先：地点团建｜项目A+项目B+项目C）
- 第一屏有情绪（秋高气爽 / 逃离工位 / 山野漫游）
- 参数卡清晰（📍地点 / ⏰时长 / 🙋‍♀️人数 / 🚌大巴 / 🎯关键词）
- 亮点密度高（⭐行程亮点速览，4—6项，带具体爽点与判断）
- 参考时间轴（🗓️ 1日行程参考 / 2天1夜参考，四位数字时刻）
- 玩法池丰富（🍁【秋日限定体验池】，3列整齐矩阵）
- Emoji有视觉导航作用
- SEO话题完整（8—10个）

### 长度
素材充足时目标 **850—1000 发布字符**，1000字符以内即可交付。

## 五、小红书4｜高密度全要素方案版

### 全要素方案写法（独立默认第四篇小红书）

这是独立的“小红书4｜高密度全要素方案版”，与高密度种草版同时默认输出。适用于用户明确要求“全要素方案长文 / 逐时段团建行程＋玩法清单＋美食住宿＋备选景点”，或输入本身很完整的团队出游方案。

**核心结构（按当前真实素材启用，不要求每一项齐全）：**
1. 情绪画面与团建价值开场，兼顾SEO和阅读钩子；
2. 明确为参考的DAY1/DAY2时段行程，重点项目下追加一到两条真实体验细节；
3. 分类玩法池，区分核心路线与其他可选项目；
4. 有事实才写地方餐饮、住宿类型、住宿设施及备选景点；
5. 2—3种按兴趣/体力/团队氛围差异的组合建议；
6. 必要提醒集中一处，8—10个真实相关搜索话题。

**排版**：`DAY 1 / DAY 2`、`⏰ 09:00`、`▪`、`🎮 🍲 🏡 📍 💡`用作扫读导航；每个大段用单独一行U+2800，不把连续横线和独立圆点当强制分隔。

**时间轴**：可以为已确定时长和真实项目拟“参考时刻”，但不得编造景区班次、真实车程、开放日期、住宿设施或承诺。同一页的多个景区/餐馆/住宿备选不自动构成同一个套餐。

**长度**：默认仍遵守高密度版1000字符内发布门。全部栏目装不下时优先保留主行程、有效选择理由和最重要的备选信息；只有用户要求未压缩长文时，才单独给策划草稿并标明需要按实际发布长度压缩。

**营销**：面向HR/行政的真实团队玩法介绍可以写，但强邀约、询价、承接及旅行服务相关内容须遵守适用的真实经营资质和平台要求，不能默认搬用参考稿中的直接招揽语句。

## 六、抖音｜攻略版（无营销）

### 单目的地
优先改写成普通用户周末散心/自驾视角：
- 周末玩法 / 户外体验 / 避坑与节奏 / 治愈放空
- **彻底消杀涉旅营销词**：严禁出现团建、HR、行政、方案、策划案、大巴接送、报价、人均、预约、下单、私信
- **严禁出现方案腔表头**：不得使用“DAY 1 / 行程安排 / 活动流程”等表头
- **硬上限最多 5 个标签**：精选 4—5 个生活/自驾/户外标签，绝不输出第6个

### 长度
约 **450—650 发布字符**。

## 七、标题规则

先找 3—5 个真实钩子，再写标题。

优先：
- 具体项目组合（如：水杉森林+骑行皮划艇+围炉）
- 真实场景与画面
- 选择难题与明确收益

降低优先级：
- XX怎么玩 / XX怎么搭 / XX怎么选 / XX这样安排 / N个方向参考

禁止靠天花板、杀疯了、老板夸爆等硬造点击。单标题 ≤ 20 字符。

---

## 八、排版与防吞行留白

段落之间统一使用单独一行的 Unicode U+2800：

`⠀`

不要使用裸空行、HTML空格、`<br>`。保持手机端阅读呼吸感。

---

## 九、发布稿净化（看不见生产过程）

最终发布稿不要出现生产过程旁白：
- 严禁出现：`原文参考 / 原素材 / 图片显示 / 根据资料 / 这里没有提供 / 本文整理` 等生产过程话语。
- 有事实就直接写，没有依据直接省略，不对读者解释。
