# 团建文案技能｜链接直入快捷提示词（2026-10-28.6）

把这段提示词和一条公开小红书/分享链接一起发给已加载团建文案技能的对话窗口即可。

## 推荐提示词

按团建文案技能处理这个链接：读取可访问的原文和图片，提取事实后直接生成默认五版。先给我五个**可单独复制发布**的完整代码块（代码块内只放标题、正文、话题，不要任何机器标记）；再给我一个**完整合并版**，把这五篇原文逐字放在一起，只增加 `<<<COPY_FORMAT:MULTI>>>`、`<<<VERSION_START:版本名>>>`、`<<<VERSION_END>>>` 分隔行。独立版与合并版内容必须逐字一致，不得压缩或省略。无法读取完整素材时请明确说明，不要猜。

## 极简用法

`按团建文案技能写五版，独立复制版＋完整合并版。链接：<粘贴链接>`

## 五版默认顺序

1. 小红书1｜自然攻略版
2. 小红书2｜大纲方案版
3. 小红书3｜高密度种草版
4. 小红书4｜高密度全要素方案版
5. 抖音｜攻略版（无营销）

每版800–950发布字符；小红书标题≤20字符，每版8–10个话题；抖音最多5个话题并执行技能中的禁词/风险规则。

## 关键格式合同

- 独立版：五个独立代码块，只有可发布文本；绝不出现机器分隔标记。
- 合并版：一个 `text` 代码块，使用机器分隔标记包住每版完整原文。
- 合并不是摘要。只加分隔标记，不改动任何文案字符。
- 如果当前对话窗口无法访问链接，要求用户补发正文/截图并说明缺失；不得伪称已经读取。
