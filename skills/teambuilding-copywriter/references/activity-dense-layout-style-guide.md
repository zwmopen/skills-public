# 高密度团建文案｜活动排列与视觉丰富感风格原料（2026-10-30）

> 本文件归属公开版 `../SKILL.md`，不是第二套文案规则。整理自用户提供的露营、阳澄湖、临安、莫干山、青山湖、桐庐、溧阳等团建文案样例，**萃取写法，不复制其他账号整篇内容，不把别的作品里的事实迁移到新稿**。仅在需要增强第3、4版密度、分类或视觉节奏时阅读；快速生产可仅执行主技能中的摘要要求。

## 一、核心审美：让读者“一眼看到玩法很多”

用户明确喜欢的不是大段解释“怎样安排更舒服”，而是：
- **项目排列密集**：一屏就出现可识别的活动名；一行一项 `✅项目｜体验`，或者一行多项 `项目A｜项目B｜项目C`。
- **分类清楚**：按水上、运动、协作、治愈、夜间、美食、营地、周边景点分池，不让一串活动变成杂乱堆砌。
- **逐时行程**：`09:00｜...` 等短节点，主项目可以加 `▶` / `▪️` 小说明，读者能迅速想象当天活动。
- **丰富而轻快**：有表情、短句、画面感和小伙伴互动氛围，信息密度高；不要把大半篇幅花在“项目别太满”“提前确认”“按需选择”等重复说教。
- **主线＋备选**：正式时间轴只放可合理衔接的少量项目，其余真实项目集中展示为“按需任选”的玩法池。丰富的是可选范围，不是虚构同一场地全包。
- **不新增虚假事实**：原始素材有6个活动，就把6个活动讲具体、重新组合与分类；**不得为了模仿“20+玩法”凭空扩成20个，不能凭示例臆造服务、价格、车程、住宿设施。**

## 三、可直接套用的排版骨架（根据事实动态选模块）

### A. 一屏活动菜单｜适合第3版

```text
{地点}团建｜{真实项目1}＋{真实项目2}✨
{两句生动但不假装亲历的场景开头}
📍{地点}｜🗓️{一日/两日}｜👥{素材确认的人群}

🔥【今天怎么玩｜按兴趣选】
🌿湖畔慢游｜{活动A}｜{活动B}｜{活动C}
🍳动手共创｜{活动D}｜{活动E}
🚣活力体验｜{活动F}｜{活动G}
🍢休闲聚会｜{活动H}｜{活动I}

🗓️【一日参考时间轴】
09:00｜{集合或开始}
10:30｜{主玩法}
12:00｜{餐饮/休息}
14:00｜{备选玩法}
16:30｜{收尾}

💡【团队按偏好搭配】{2-3组真实项目组合}
{集中一句必要限制}
{8-10个精准话题}
```

注：分类只放用户本套素材确实支持的活动，不能为了凑四类创造新项目。单日素材不写D2。

只要求视觉框架丰富，不强制完整填满所有栏目；800–950字符内优先保留活动、时间轴及有用细节。

这里的活动名数量取决于素材，不能补不存在的活动；单列“周边景点”不等于它们与当前主线同场地或可同日串联。

## 四、东钱湖素材的安全示例（用用户当轮提供的具体信息示范写法）

> 此例仅示范“丰富的活动菜单＋合理备选”，不要当作后续安吉、临安、桐庐的事实。

```text
🌿【湖边慢玩】湖边散步｜采摘｜垂钓
🍳【动手共创】分组备菜｜土灶野炊｜一起掌勺
🚣【户外活力】皮筏艇｜草坪趣味互动｜环湖骑行
🍢【湖畔聚会】露营烧烤｜自由聊天｜团队合影

🗓️【一日时间参考】
09:00｜集合出发
10:00｜湖畔慢游，采摘或垂钓
11:30｜分组备菜＋土灶野炊
14:00｜皮筏艇/草坪游戏/骑行择一到两项
16:30｜休息，烧烤或自由活动

🎯【3种搭配】
松弛：采摘/垂钓＋湖边休息
协作：土灶野炊＋草坪小游戏
活力：皮筏艇＋骑行（按条件择重）
```

**真实项目与参考钟点均来自用户这套东钱湖原稿；分类、顺序只是文案表达，不代表单一场地全部可提供。** 未确认时不用写“已经包含、全包、提供接送”等实质经营承诺。

## 五、从样例中“学”与“不学”的边界

**该学：**
- 10秒能扫到多个具体活动，文案主线也清楚；
- `✅项目｜有画面感的短解释` 比一个大段落塞多个名词好；
- 分类玩法池、主行程、替换项目各自分区；
- 用短表情符号、视觉层级、时刻、单双列清单提升丰富感；
- 一篇同时给出内容价值、具体玩法和有用的选择判断。

**不能迁移：**
- `免费get方案`、引导评论/私信、`一站式全包`、`闭眼冲`、`15–300人可接`、固定车程、`人均500–1000`、编造好评或亲历等销售/事实承诺；
- 抄袭样例的原句和具体活动至其他目的地；复制示例话题与地点；
- 在无经营资质的抖音账号上直接照搬小红书的“团建路线＋人数＋餐食住宿＋接送＋获客引导”组合；涉旅经营内容先检查真实主体资质与平台要求；
- 过度密集的空泛感叹词、无依据的“必玩”“都有”“全部免费”“当日开放”。

## 六、800–950字符内的优先级与验收

1. 标题和前3行自然、有真实体验画面，**不把内部版本名“全要素”当对外标题**。
2. 第3版优先在前半篇出现**至少一组有意义的活动清单**，通常4–8个独立项目，具体数量跟随素材；亮点必须具体。
3. 第4版保留完整的、有四位时刻的参考排程；一日只排一日，两日才分D1/D2。
4. 如果素材有足够种类，可分 `自然/协作/动感/餐饮/休闲`；若类型不足，只用适用的类别。
5. 区分主线与备选，不制造各项目同店包含或跨景点不切实际的串联。
6. **集中一句**提醒条件限制，避免每个栏目都出现“提前确认”“不要排满”。
7. 末尾精准话题。检查用户当轮事实、长度与版式；不要为了“丰富”补造具体场地、价格、交通或服务。
