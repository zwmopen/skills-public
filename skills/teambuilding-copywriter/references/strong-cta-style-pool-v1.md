# 小红书强转化｜10种内容结构模板池 V1.0（2026-11-16）

> **用途**：供 `teambuilding-copywriter` 默认第4篇「小红书强转化版」选模。不是“把地名换一下就整篇照搬”，而是**保留结构、重写开头与具体玩法、只填当前批素材支持的事实**。每篇样本都出自用户本次及上一轮直接粘贴的团建参考笔记；不代表任何样本经过转化率验证。使用时优先读取 `strong-cta-style-pool-v1.json` 进行条件匹配，需要随机抽取时运行 `../scripts/select_strong_cta_style.py`。

## 核心变量（不要求用户逐项填写，直接从本轮素材提取）

- `{目的地}`、`{客群与痛点}`、`{季节与视觉钩子}`、`{主题}`、`{真实时长}`；
- `{项目1...N}`、`{对应动作画面}`、`{强度与适合谁}`、`{已提供时刻}`、`{正餐/夜场}`、`{可选路线}`；
- `{已证实服务能力}`、`{账号准入情况}`、`{允许的承接方式}`、`{具体能兑现的行动回报}`。

素材缺什么就**删掉相应模块**，不拿别人的季节、人均价格、车程、人数上限、交通服务、私汤/酒店设施、免费权益来填空。原稿有时间表才可保留原时刻；无时间表允许输出“参考时段”但不虚构实际运营时刻与转场可行性。所有模板均不得给出假“我们上周刚带队”的亲历口吻。

## 样本映射与10个可复用模板

### XCTA-01｜百丈岭：反套路痛点 → 一个王牌景象 → 主线日程 → 延伸可选

**样本特征**：反对乏味团建；雾凇有强画面；先讲一个主景点，再给7:30—19:00的完整路线，随后讲可升级两日的可能性。

**素材门槛**：≥1项有辨识度的实景/玩法，最好有参考时段；没有雾凇/雪景不能写冬景。

**套用结构**：
1. 开场两三句：`{旧团建痛点}？换成{当前目的地的独特项目+具体视觉}，这才是{客群}更容易期待的{活动}`。要原创，不照抄原帖语气。
2. `📍{目的地}｜⏰{真实时长}｜✨{3个真亮点}`
3. `🌿【主角怎么玩】` 2–4项具名项目及动作；不编“必看雾凇”。
4. `🗓️【{日期/时长}时间线】` 若有钟点就逐行安排具体动作，若没钟点用 D1/D2 时段。
5. `➕【还想更轻松/更刺激】` 当前素材内才有的备选活动。
6. `💬` 最后给一条**真实可兑现**的业务下一步；权限不明写待审核候选稿，不装成可领取免费材料。

**去重位**：冲突角度（加班式拓展/只有吃饭/不停赶场）、视觉主角、场景顺序、结尾回报。

### XCTA-02｜龙坞茶山：前3行摆3个好玩点 → 6–8项玩法菜单 → 一日活动 → 三个理由

**样本特征**：目的地和时长非常显眼；每一项都写“怎么玩”，而不是只有项目名；最后3条组织者选择理由。

**素材门槛**：≥5项真实、互不重复的项目；不够5项不选本模。

**套用结构**：
1. `{目的地}{真实时长}{团队场景}！{项目A}/{项目B}/{项目C}，各有画面和参与感`
2. `📍{真实地点}｜🕒{真实时长}｜🎯{1–2个适用人群}`
3. `🌿【体验亮点】` 5–8个 `✅{项目}｜{具体动作＋视觉或互动价值}`，按素材数量输出。
4. `🍴【吃与休息】` 横排3项以内真实餐食/茶点/休闲内容。
5. `🗓️【{时长}参考时间线】` 具名动作、时间表。
6. `💡【为什么适合这类团队】` 三个具体、源于事实的理由，不填“省心无忧/极致性价比”空话。
7. 已核实资格/权益时，一条清楚的下一步。

**去重位**：第一个突出点、玩法排列顺序、理由（不赶路/适合慢热/雨天室内等必须有事实支持）。

### XCTA-03｜青山湖：景象反差 → 分类型项目池 → A/B真实路线 → 聚会场景

**样本特征**：“不是游客挤在一起，而是水上森林、露营与皮划艇”的具体反差；水上、陆地、秋日、夜间、团队玩法分类；一日A和两日B分开。

**素材门槛**：≥4真实活动，且存在**实际可行的两个不同完整路线/时长**，不能自动把两个时长算已证实。

**套用结构**：
1. `不是{组织者不喜欢的体验}，而是{景象A}＋{玩法B}＋{聚会C}`
2. `📸【值得看的3–5个真实场景】`
3. `🎯【按需求挑玩法】` 3–5类，按素材分，不凭空造项目。
4. `🗓️【A｜{真实第一条路线}】` 3–6个行程节点。
5. `🗓️【B｜{真实第二条路线}】` 与A区分主线，不能把候选地点默认串联。
6. `🍽️【吃与夜晚】` 若当前有对应事实。
7. 一条行动回报明确的CTA（业务资格为前提）。

**去重位**：A/B区别（轻运动/松弛、日程长度、餐饮形式、夜场）基于事实设置。

### XCTA-04｜江浙沪古道：季节共鸣 → N条线路清单 → 难易/人群筛选

**样本特征**：桂花香、秋风、11条古道，每条给起终点／长度／爬升／风景。**核心是“合集”，不必重复整条商业行程。**

**素材门槛**：当前素材至少提供**5条真实独立路线**，若只有“安吉2天1夜一家别墅”绝不可套成“11条路线”。

**套用结构**：
1. `{本批真实季节感或天气}，{目的地区域}的{活动}可以排进计划`，不得编不存在的桂花和秋天。
2. `🥾【{事实条数}条{真实类型}路线】`；每条 `{路线名}｜{有据可写的距离/时长/难度}｜{具体特色}`。
3. `🎯【按团队体力分】` 轻松/中等/进阶，仅在坡度与距离等信息足够时标注。
4. `🗓️【一条代表路线怎么走】` 只有当前有时间资料时才补参考时段。
5. 出行安全信息单独简短一段；不能把未验证的距离/补给/爬升编出来。
6. 合规业务CTA。

**去重位**：排序方式（难度/时长/景观）、季节钩子、路线数量；不得固定11条。

### XCTA-05｜桐庐：目的地被低估 → 两日完整行程 → 刺激/休闲玩法双池

**样本特征**：先讲“被低估”＋具体山水玩点；两日时间线后有刺激、探险、乡村、夜间多玩法菜单。

**素材门槛**：≥5项真实项目、明确两天一夜与D1/D2素材，且存在不同强度的备选。

**套用结构**：
1. `{目的地}团建别只盯着{常见单一玩法}，{真项目A}＋{真项目B}＋{真项目C}已经够丰富`
2. `📍{目的地}｜⏰2天1夜｜✨核心看点`
3. `🗓️【DAY1｜{主线}】` 具名地点、吃饭、下午活动、夜场。
4. `🗓️【DAY2｜{主线}】` 备选明示二选一。
5. `🔥【想刺激的选】` / `🍵【想慢玩的选】` 各2–4项。
6. `🍴【餐饮住宿】` 仅当当前材料说明具体可能性，不套竞争对手的包含项。
7. 与这篇真实项目匹配的CTA。

**去重位**：首屏痛点、D1/D2主角、活力/休闲项目排列。

### XCTA-06｜四明山：打工人反感尴尬团建 → 户外农趣＋季节画面 → 美食亮点

**样本特征**：担心“换个地方开会”、怕被迫尬玩，紧接着抛出秋景、农庄、越野与农家餐；吃什么也同样具体。

**素材门槛**：≥4个真实项目，户外与聚餐均有真实来源；季节景观必须确有依据。

**套用结构**：
1. `还在{组织者/员工痛点}？{地点}可以把{户外主角}和{聚餐体验}放在两天里`
2. `📍{地点}｜⏰{天数}｜🎯{适合的团建需求}`
3. `🗓️【{参考时段/两日}】` 把活动时间展示在靠前位置。
4. `🍁【具名自然/农庄亮点】` 3–5项，每项给真实体验画面。
5. `🍲【当地餐食】` 真实菜品菜单；不凭空写时令料理。
6. `🎮【可替换互动】` 2–4项。
7. 在可用资格下给下一步；不要声称“大巴直达/全程落地”。

**去重位**：员工痛点、景象主角、美食场景、互动强度。

### XCTA-07｜黄山宏村：松弛文化感 → 古村与自然地标 → 文化手作/团队互动

**样本特征**：不是一上来数器材，而是古村水墨感、山景和当地美食；两日行程＋文化项目＋具名景点。

**素材门槛**：当前素材确有文化景点、手作/文化活动（至少1项），且可供排程的事实；无文化内容时不选。

**套用结构**：
1. `{地点}不是只能{大众认识的单一标签}，还有{古村/文化体验}＋{自然体验}＋{共同活动}`
2. `📍{主地点}｜{时长}｜{3个实项目}`
3. `🗓️【DAY1】` 和 `【DAY2】`；跨地转场以来源为准。
4. `🎨【文化互动】` 真实手作、游戏或共同任务，说明动作。
5. `🏞️【具名景点】` 仅有真实地名才写。
6. `🍜【吃什么】` 具体菜品（当前有事实）。
7. 具体组织者收获与合规下一步。

**去重位**：文化主线、图文视觉、历史元素、美食段落。

### XCTA-08｜莫干山：下午A动感/B松弛 → 夜晚聚餐 → 次日文化慢逛

**样本特征**：第一天下午有明确“刺激A/竹海轻松B”两组互斥选择，夜晚共享庭院BBQ或轰趴；第二天换文化/村落。

**素材门槛**：同一时间至少两条来源明确的不同强度可选玩法，且有夜场/第二天内容。

**套用结构**：
1. `{地}两天一晚，不必全部人都冲同一个项目。活力组选{项目A}，休闲组选{项目B}`
2. `📍地点/时长/核心项目`
3. `🗓️【DAY1】` 上午/午餐 → `下午A｜{运动玩法}` / `下午B｜{休闲玩法}`（不同点位交通未证实则明确**替代路线，非同一团队同步分流**） → 晚间餐饮/轰趴。
4. `🗓️【DAY2】` 文化/农事/手作，再收尾。
5. `🎯【按喜好替换】` 3类，不附赠未证实项目。
6. 合规CTA。

**去重位**：AB组合、选项顺序、白天/晚间的反差。

### XCTA-09｜千岛湖：季节景象和水景 → 两日行程 → 多项目详细拆解

**样本特征**：首屏“湖景+骑行+围炉”具象化；两天详细路线，后面再补水上、陆地、夜间和民宿体验，读者先有骨架后看选择。

**素材门槛**：有真实两日主线、≥4个不同项目；未确认住宿时不可硬加入湖景民宿。

**套用结构**：
1. `{地点}的{真风景A}＋{项目B}＋{聚会C}，比只做{常见单项}更有变化`
2. `📍{地点}｜⏰2天1夜｜🎯{主题}`
3. `🗓️【DAY1｜{主线}】` 日期钟点按现有素材。
4. `🗓️【DAY2｜{主线}】`
5. `🎯【玩法池】` 水上/陆地/互动/夜间（仅当前出现的类别）。
6. `🍽️【餐饮/休闲】` 具体真实体验。
7. 合规CTA。

**去重位**：首日与次日侧重点、玩法池的类别数量、景象钩子。

### XCTA-10｜阳澄湖：季节限定吃喝/景色 → 当季理由 → 两种时长

**样本特征**：秋天湖畔吃蟹、芦苇和骑行的季节价值突出；可选2天1夜和一日返程，搭配具体餐饮和周边景点。

**素材门槛**：本批素材**确有时令项目或明确季节主题**，且至少有一条可靠时长安排；若素材只有冬季溧阳温泉，禁止用“秋季吃蟹”钩子。

**套用结构**：
1. `{季节}快到了/正适合{地点}{有事实依据的时令特色}；{视觉A}＋{美食B}＋{活动C}`
2. `🍂【这个时段值得玩的3件事】` 写真实时令价值，不编“最低价/最稀缺”。
3. `🗓️【已知时长路线】` 按素材。若确有另外一个独立时长才增加 `【B备用时长】`，否则省略。
4. `📸【周边场景】` 仅素材已有的景点与风景。
5. `🍲【当季餐食】` 无真实菜品则省略。
6. 适合HR的选择理由与合规下一步。

**去重位**：季节痛点、美食/景色/活动三角主轴、A/B是否存在。

## 选模板机制（必须执行，不是十套每次从头到尾全贴）

1. **先提取事实**：当前地点、场景、项目数量、真实路线条数、是否2日、有无时令核心、有无文化/农事、有无两套可行路线、有无主角视觉、有无运动＋休闲、是否有餐饮。
2. **先过滤后随机**：只有符合各模板“素材门槛”的模版才进候选池；如果本批只有一个温泉别墅，路线合集型XCTA-04、双线型XCTA-03必须排除。
3. **有执行环境时进行真实抽样**：使用 `python scripts/select_strong_cta_style.py --facts current-facts.json --history .cache/strong-cta-history.json`；该脚本只从符合素材的候选池随机选择，并尽量排除最近3次。
4. **没有执行环境时**：在本次可用的候选池中由模型随机选1套；有可读历史就避开最近3次；**不宣称已经执行脚本或实现跨会话可靠去重**。
5. **去重不止换地名**：同时变化至少3个维度——钩子、场景顺序、段落模块、A/B线结构、句式节奏、项目展示方式、CTA价值。标题和首屏不允许模板字句原封不动。
6. **选完原料模版再写小红书第4篇**，其它五篇使用各自既有规则。模板ID仅放在内部回执/可选元数据，**不得混入公开发布正文或MULTI机器标记**。
7. **强转化的“强”指读者知道下一步的实际价值**，不等同于评论暗号或未经证实的“免费1V1”。经营/平台权限未核实时，强转化只能标在文案外作待审核候选稿。
