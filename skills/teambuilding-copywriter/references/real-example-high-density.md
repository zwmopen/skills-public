## 必学写作指纹

1. **第一屏就有情绪**：不是“基础信息如下”，而是“秋高气爽 / 逃离工位 / 山野漫游 / 追风”。
2. **第一屏马上堆价值**：季节 + 目的地 + 场景 + 项目丰富度 + HR可抄作业。
3. **参数卡视觉很强**：`📍 | / ⏰ | / 🙋‍♀️｜ / 🚌 | / 🎯 |`。
4. **亮点之间用“•”断开**，让长文看起来不重。
5. **亮点不是名词清单**：项目名后跟一句“为什么爽 / 什么画面 / 跟上班形成什么反差”。
6. **路线不是简略上午下午**：有条件时直接给完整时刻，让稿子像一套能马上拿去用的参考安排。
7. **DAY 字样有视觉设计**：`𝗗𝗔𝗬❶ / 𝗗𝗔𝗬❷`。
8. **自选项用 ✅**，一眼看出“不是全部都要玩”。
9. **最后再放玩法池**，制造“这个目的地真的很多东西能玩”的丰富感。
10. **Emoji 不只是装饰**：每种项目换不同图标，形成扫读导航。
11. **话题是搜索矩阵**：大地域 + 目的地 + 项目 + 方案 + 一日/徒步等长尾一起铺。
12. **整体不是保守攻略腔**：允许更有热度、更有营销感、更像运营成稿；但新项目客观事实仍不得从这个范例跨稿搬运。
