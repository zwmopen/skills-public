## 范例 1｜莫干山2天1夜（分天动线 + 时刻穿插 × 单场地抖音去团建化）

### 🔍 写作指纹（Writing Fingerprint）
- **平台与表现体组合**：
  - 小红书：`xhs-natural-ops-v1（红书自然）× flow-day（分天动线）+ timeline（时刻穿插）+ decision-quick（HR怎么搭）`
  - 抖音：`douyin-life-avoidance-v1（抖音攻略）× 单场地去团建化（周末秋日出行视角）`
- **为什么写得好**：
  1. **开头直接给判断**：不写空洞背景，直接点明“第一天负责玩嗨，第二天进山徒步，两天节奏完全不重复，不会全程硬拉练”。
  2. **项目清单带取舍建议**：列出 7 个山野项目后，立刻补一句运营级判断——“不建议为了‘项目多’全部塞满，10人左右的小团队选2—3个核心项目，体验反而更完整”。
  3. **真实徒步数据不虚美**：把里程（12km）、爬升（650m）、耗时（5—6小时）、路况（土路+石阶）摆清楚，并诚实提醒“对平时完全不运动的人还是有一定挑战”。
  4. **💡HR怎么搭模块具体可执行**：按“想互动多 / 想松弛 / 团队体力好 / 体力差异大 / 预算有限”五种真实痛点给出加减法。
  5. **抖音彻底重写而非删短**：完全剥离“团建、HR、10人起、预算700+”，改成“第一天负责热闹 / 傍晚负责放松 / 第二天负责进山 / 最后真正把秋天看够”的自然出游节奏，5个生活标签干净利落。

## 范例 9｜杭州山野田园大纲方案母稿（小红书2｜outline-plan-v1）

> **来源说明**：2026-10-10 用户主动提供，明确要求作为后续“**小红书2｜大纲方案版**”的参考文案。只学习结构、信息密度、栏目节奏、Emoji 用法与展开方式；严禁跨作品复用其中具体地点、时长、玩法、人数或时间点。

### 🔍 写作指纹（Writing Fingerprint）
- **定位**：不是自然随笔，也不是摘要卡，而是给 HR / 行政直接收藏做方案的完整大纲笔记。
- **标题**：`地点 + 团建 + 3个场景/玩法关键词`，一眼看出目的地与玩法组合。
- **开头**：先解决痛点——不想传统拓展、不想赶行程；再给组合思路，告诉读者这套怎么把参与感与放松感同时保留。
- **信息卡**：使用 `🟡【基础信息】`，只放有事实依据的地点、时长、人数、出行、关键词。
- **推荐理由**：用 `🌾【为什么推荐这种玩法？】` 给 3 条明确原因，不空喊“好玩”。
- **DAY 展开**：按 DAY1 / DAY2 组织，时间轴只在素材提供时使用；每个时段写项目、体验和节奏，不只列名词。
- **亮点总结**：用 `✨【这套组合的亮点】` 收束，强调动静关系、场景特色、自由组合与适用场景。
- **排版**：高密度但层级清晰，Emoji 做导航，不做装饰墙。
