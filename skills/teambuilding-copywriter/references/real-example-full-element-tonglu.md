## 必学“可迁移手感”

1. **第一屏5行以内交付承诺**：具体场景或季节反差、行程价值、队伍规模（有事实才写），不只喊“热门团建”。
2. **行程是主轴**：DAY1 / DAY2分日、`09:00`四位时刻、每个节点有动作和体验；核心景点下用`▪`写2条具体体验，而非仅列项目名。
3. **具体深度**：按场景打包项目，至少有一处“为什么这样安排 / 这类体验适合谁”。
4. **尾部货架展示**：`玩法清单` / `本地美食` / `住宿选择` / `备选景点` / `3种搭配`是按素材富余度启用的模块，不要因模板存在而编服务配置。
5. **“同源异构”**：相比自然攻略版，此版本明显偏B端可收藏的详细路线/备选决策，允许丰富SEO与种草气氛；与大纲方案版相比，更多项目名、情绪、具体体验与分类栏目。
6. **紧凑阅读**：小标题简洁且信息性强；`⏰`适合关键行程；清单内部不在每条之间插U+2800。整体段落仍优先单独一行U+2800，不复制范例中的`———`或`.`为强制视觉分隔。
7. **可选 ≠ 同场地全包**：原文是多个候选玩法与住宿/景区汇总；不得暗示一价全含、同一天必然全能安排。
8. **商业承接单独审查**：HR/行政提示可以在小红书读者语义中出现；强CTA、旅游服务履约、资质要求不可因为是小红书就自动视为合规。
