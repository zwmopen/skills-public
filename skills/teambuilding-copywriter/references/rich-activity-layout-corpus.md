# 高密度活动排列风格原料｜用户提供的优秀范例（2026-10-30）

> **定位：这是写法原料，不是当前团建项目的事实数据库。** 样例均由用户在2026-10-30提供，内容未经独立核验；其中可能有虚构/过期事实、商业承接词、价格、车程、资质、场地配置与夸张形容。写新稿时**只学习活动排列、层级、视觉符号、紧凑节奏、候选池与逐时结构**，绝不能照搬跨目的地项目/套餐/接送/用户评价。抖音的独立无营销规范仍以 ../SKILL.md 为准。

## 一、这批参考真正想保留什么

**不是“长篇全要素说明书”，而是“读者扫一眼就知道很多种玩法”的信息架构。** 用户明确喜欢：
- 一屏先见到【标题与3–5个具体玩法】；第一个大模块就给密集的活动名称，而非长段“别排太满/逐项确认”。
- `✅项目名称｜一句有画面感的描述` 或 `分类：项目A｜项目B｜项目C`，每行出现一个可识别的活动或可验证的体验，不重复一个活动的同义词。
- 项目按照**水上/草坪/手作/餐饮/休闲/互动/夜场/周边**归类，分组紧凑、可扫读。
- 短参数卡 `📍地点｜⏰时长｜👥人数（有证据才写）`；高密度版本按证据放**参考逐时行程**；最后补**一组精简备选清单**、少量真实判断。
- 一日素材只能写一日排程；两日素材才写DAY1/DAY2；单营地型突出“项目区域”，跨景点型突出“主路线＋周边替换”。
- **丰富感来自事实覆盖率和结构清晰，不是项目数量口号**：6个真实项目可写6种不同的活动条目，不能编成“20+玩法”“几十个项目”。如果只有5项素材，不增加未证实的“围炉/真人CS/手作”。

## 三、真正的生产规则｜在800–950字符内做“丰富但不乱”

### A. 高密度种草（小红书3）
1. 短标题（地点＋2–4个实际项目）与两三句画面开场；
2. 真实参数卡（仅有依据项）；
3. **首个信息主模块就放4–6项高辨识度亮点**：`✅项目｜10–30字真实体验`；
4. **玩法池至少做两类、通常三类**，用 `｜` 并列当前真实活动，不能为凑行数拆同义词；若当前仅有少量项目，就做“核心/备选”两栏；
5. 单日给单日参考时刻，两日给D1/D2，不把所有备选塞进当日固定路线；
6. 最后仅一组简短实用提醒，8–10相关话题。

### B. 高密度排程（小红书4）
1. **先让读者看懂逐时主路线**：09:00→12:00→14:00→18:00等（拟定时间明确标为参考）；
2. 同一项目有多个确认的玩法时，节点下用1–2行`A｜B｜C`展开；
3. 紧接着分别放`🎮玩法池`、`🍲餐饮`、`🏡住宿`、`📍周边替换`中有事实支持的部分；
4. 最后按队伍喜好给2–3个不同选法；不要重复说三遍“别排太满/以实际为准”；
5. 一日项目不增加DAY2，两天项目不靠编造路线拉满。

### C. 东钱湖的一日素材示范：**仅用该套已提供事实**（不是新增项目）

```text
🌿【湖边慢玩】湖畔漫步｜采摘｜垂钓
🔥【动手吃饭】分工备菜｜土灶野炊｜露营烧烤
🚣【户外撒欢】皮筏艇｜草坪趣味互动｜环湖骑行
📸【自由时光】湖边聊天｜草坪休息｜合影

🗓️一日参考安排｜时间可调整
09:00｜集合出发
10:00｜湖边走走＋采摘/垂钓择一
11:30｜分组备菜＋土灶野炊
14:00｜皮筏艇/草坪互动/骑行择一到两项
16:30｜休整，烧烤或自由活动
```

这里“丰富”是**展示选项与分组**，不等于同一农庄全部包含，也不等于所有项目一天全部执行；水上项目须看当季、资质、场地、安全条件。**不能因看到原稿而给东钱湖加卡丁车、围炉煮茶、窑烤披萨、真人CS**。

## 四、写作禁区｜尤其不能学习的样例内容

- `HR闭眼冲`、`全包`、`免费get策划+执行`、`留下人数`、`大巴全程接送`、`不接散客`、`10–500人`、`人均559`、`1小时直达`、`老板满意`、`我们刚组织完零踩雷`：全部视为示例里的营销/事实陈述，**不得复制或外推**，更不能伪装真实体验。
- `20+玩法`、`所有设备齐全`、`一站式`只在当轮有逐项证据且平台允许时才考虑，通常优先改为客观项目列表。
- 标题尽量让具体项目说话，不默认照搬夸张、绝对化、高承接的口吻。
- 一旦用户给出的是商业旅游经营内容，文案优化不能替代平台资质审查，也不能借“普通人分享”的语气掩饰真实商业用途。
