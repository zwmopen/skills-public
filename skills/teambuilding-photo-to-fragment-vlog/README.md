# 团建图文转碎片Vlog Skill

**版本**：v1.1.0（2026-11-12）  
**类型**：公开的可复用AI内容制作工作流（不是自动生成可下载视频的程序）

从真实团建/周边游的照片、拼图、TXT与图文笔记中，生成能够交给 **Google Flow** 的片段提示词，并提供独立口播、镜头表、剪映剪辑顺序、真实度检查和积分预算。

## 入口

- 主技能：[SKILL.md](SKILL.md)
- 版本记录：[CHANGELOG.md](CHANGELOG.md)
- 直读地址：https://raw.githubusercontent.com/zwmopen/skills-public/main/skills/teambuilding-photo-to-fragment-vlog/SKILL.md

## 使用方式

在 ChatGPT、Codex、Claude、Cursor 等支持读取网络文本或自定义技能的工具中，加载上面的主技能文件，然后提供本次原始图片和文案，要求「按技能生成30秒碎片Vlog制作包」。

输出包括：素材识别与事实账本、模式选择、完整口播、逐镜头时间线、整段版与逐镜头版Flow提示词、剪映拼接清单、积分预算及发布质检。

**默认30秒、默认混合模式**；也可以指定15、45、60秒，或指定整段/逐镜头生成。用户可一次提交所有原料，但视频生成可能仍需按镜头在 Flow 内执行，再剪辑组装。

## 真实度与授权

优先保留原场地、人物、设施、食物和活动结构；去除多余文字不得损害第三方版权信息。使用网络素材时必须检查许可，不能把他人记录伪装成本人实际到场。人物替换是有权限时的可选处理，不是强制步骤。

## 限制

- 本技能提供方案和提示词，不保证已连接 Google Flow/剪映，也不保证可在所有账户或模型下自动生视频。
- 生视频额度、模型能力、输出时长和积分价格可能变化，遵循当前Flow界面。
- 公开技能中不包含用户的私有图片、个人账户、API密钥或本地工作目录。
